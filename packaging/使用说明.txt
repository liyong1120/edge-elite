棱锋精英 / EDGE ELITE
5v5 战术射击（磐垒 vs 锐刃）—— 绿色免安装版
================================================

【怎么玩】
双击 EdgeElite.exe 即可启动，无需安装。

重要：EdgeElite.exe 与 EdgeElite.pck 必须放在同一个文件夹里，
      两个文件要一起移动、一起删除。若要改名，请把 exe 和 pck 改成
      完全相同的名字（例如 棱锋精英.exe / 棱锋精英.pck），否则无法启动。

【关于这两个文件】
EdgeElite.exe 是运行程序，EdgeElite.pck 是资源包——
游戏里的关卡、模型、贴图、音效、代码全部打包在 pck 里。
所以解压后只有这两个文件是正常的，并没有少文件。

【系统要求】
- Windows 10 / 11（64 位）
  注意：不支持 Windows 7 / 8 / 8.1，系统过旧会无法启动
- 支持 Vulkan 的独立显卡或较新的核显
- 首次启动会稍慢，属正常现象

【操作】
WASD          移动
Ctrl / C      蹲下
空格          跳跃
鼠标左键      射击 / 挥刀
鼠标右键      开镜（狙击枪）/ 消音切换
R             换弹
数字键 1-5    切换武器槽位
B             购买菜单（购买阶段）
E             安包 / 拆包 / 拾取
Tab           查看战绩
+ / -         增减机器人
F8            截图（保存在程序目录）
Esc           暂停 / 菜单

【联机】
支持局域网对战，可在主菜单进入联机房间后创建或加入。
