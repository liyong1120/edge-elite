# 素材规格清单（AI 生成）

> **本文档设计目的：直接复制粘贴给 AI 工具（Meshy.ai / Tripo3D / Rodin / 可灵等）生成可用素材。**
> 生成后导出 `.glb` 文件，按文件名放入 `cs-godot/models/` 对应目录，游戏自动加载。

---

## 一、AI 工具选择

| 工具 | 类型 | 输出格式 | 推荐指数 | 适合场景 |
|------|------|----------|----------|----------|
| **Meshy.ai** | 文字/图片→3D | GLB/GLTF | ⭐⭐⭐⭐⭐ | 武器、角色（支持多边形数控制） |
| **Tripo3D** | 文字/图片→3D | GLB/GLTF | ⭐⭐⭐⭐ | 武器、道具 |
| **Rodin by Hyper** | 文字→3D | GLB/GLTF | ⭐⭐⭐⭐ | 写实风格武器 |
| **可灵AI 3D** | 图片→3D | GLB/GLTF | ⭐⭐⭐ | 中文支持好 |
| **Blender + 脚本** | 参数化建模 | 全格式 | ⭐⭐⭐⭐⭐ | 精确控制（需基础） |

**建议优先用 Meshy.ai**（支持面数控制 + 直接导出 GLB + 有免费额度）

## 二、通用约束（复制这段给所有 AI）

每次生成前，把这段作为**前缀提示词**：

```
输出格式：GLB (glTF 2.0 Binary)
单位比例：1 单位 = 1 米
坐标轴：Y 向上
朝向要求：角色面朝 +Z，武器枪口朝 −Z
面数上限：见下方各模型要求
风格：低模写实风格（90年代末军事游戏质感）
贴图：内嵌材质，PBR metalness，单张≤512×512
UV展开：UV必须展开，无重叠，合理布局
材质命名：使用规范命名（如 "mat_ct_body"、"mat_ak47_metal"）
顶点颜色：如需要，可使用顶点颜色区分材质区域
禁止：不要骨骼/动画（除非下面明确要求）
禁止：不要发光/霓虹/科幻元素
禁止：不要环境反射贴图（GLB内嵌材质已包含）
```

## 五、操作流程（三步完成）

### 步骤一：生成

1. 打开 [Meshy.ai](https://www.meshy.ai) 或 [Tripo3D](https://www.tripo3d.ai)
2. 注册登录（有免费额度）
3. 点击"Text to 3D"或"AI 生成"
4. 复制上方对应模型的提示词粘贴
5. 等待生成（通常 30 秒 ~ 2 分钟）

### 步骤二：导出

1. 生成后预览，满意后点"下载/Export"
2. 选择 **GLB** 格式
3. 下载到本地，重命名为清单中的文件名（如 `AK47.glb`）

### 步骤三：放入项目

```
cs-godot/
├── models/
│   ├── characters/              ← 放角色模型（CT和T）
│   │   ├── player.glb          ← CT角色
│   │   └── t_player.glb        ← T角色
│   └── fpv/                    ← 放武器模型（第一人称视角）
│       ├── AK47.glb
│       ├── M4A1.glb
│       ├── AWP.glb
│       ├── Knife.glb
│       ├── Deagle.glb
│       ├── Glock.glb
│       ├── USP.glb
│       ├── MP5.glb
│       ├── P90.glb
│       └── ...（其他武器）
```

放入后，启动 Godot 项目，删除 `.godot/imported/` 文件夹，重新打开项目让 Godot 导入新素材。

## 六、AI 生成后常见问题

| 问题 | 解决方法 |
|------|----------|
| 面数超标 | 在 Meshy 设置里调低"Poly Count"；或导入 Blender 用 Decimate 减面 |
| 朝向不对 | 在 Blender 里旋转模型（角色 R Z 90° 或武器 R Y 180°），重新导出 |
| 尺寸不对 | 在 Blender 里缩放（S 键），角色站高调到 1.8m，武器长 0.6~0.9m |
| 材质丢失 | 确保导出时勾选"Include Materials"；GLB 格式内嵌材质不会丢 |
| 太光滑/太科幻 | 提示词加"low poly, retro, 1999, military, gritty"等关键词 |
| 手臂遮挡 | 第一人称武器不要包含手/手臂（提示词已写明"禁止手/手臂"） |

## 七、自检清单

生成并放入后，运行游戏检查：

- [ ] 角色模型高度约 1.8 米（不是巨人也不是小人）
- [ ] 武器枪口朝前（-Z），不会倒置或侧翻
- [ ] 武器大小合理（手枪约 0.2m，步枪约 0.7m）
- [ ] 无多余的手臂/身体遮挡画面
- [ ] 颜色/材质符合经典风格（不要霓虹/发光）
- [ ] Godot 打开项目无红色报错
